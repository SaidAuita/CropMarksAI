## 2. Архитектура и функциональные компоненты

### 2.1. Высокоскоростной геометрический движок (CropMarkEngine)
- **Прямое векторное построение через C++ SDK**:
  - Создание контуров через `sAIArt->NewArt(kPathArt, ...)` и `sAIPath->SetPathSegments`.
  - Назначение параметров обводки через `sAIPathStyle`: цвет Registration (`sAICustomColor->GetCurrentRegistrationColor`), butt cap (`kAIButtCap`), miter join, отсутствие пунктира и заливки.
- **Интеллектуальная обработка масок и направляющих**:
  - Выявление обтравочных масок (`kArtIsClipMask`) и расчет меток строго по габаритам обтравочного контура.
  - Игнорирование направляющих (`sAIPath->GetPathGuide`) и служебных объектов.
- **Поддержка режимов границ**:
  - `Geometric Bounds`: чистые габариты контуров без учета толщины обводки (`kControlBounds | kNoStrokeBounds | kNoExtendedBounds`).
  - `Visible Bounds`: полные визуальные границы с учетом толщины обводки (`kVisibleBounds`).
- **Автоматическая дедупликация линий**:
  - Позиционный кэш с порогом `0.002 pt` предотвращает наложение дублирующих линий при плотной верстке карточек и спусков.
- **Белая маскирующая подложка (White Knockout Underlay)**:
  - Создание фоновой белой линии толщиной `strokeWidth + 1.0 pt` под цветной меткой для четкой видимости на темных фонах.
- **Автоматическое перемещение назад (Send to Back)**:
  - Опускание всех меток и групп под исходные объекты макета через `sAIArt->ReorderArt(..., kPlaceBelow, lowestSelectedArt)` (или `kPlaceInsideOnBottom` текущего слоя).
- **Интеграция с Undo / Redo**:
  - Регистрация действия в палитре истории через `sAIUndo->SetUndoTextUS` — отмена всех меток в один шаг Ctrl+Z.

### 2.2. Пользовательский интерфейс и адаптивные темы
- **Докируемая панель Illustrator (AIPanel)**:
  - Регистрация в меню `Window -> Make Crop Marks AI` с иконкой палитры.
  - Регистрация команд в меню `Object -> Utilities`.
  - Минимальные габариты 240x400, адаптивная компоновка элементов.
- **Адаптация под 4 цветовые темы оформления**:
  - Опрос `sAIUITheme->IsUIThemeDark()`, `sAIUITheme->GetUIThemeColor` для фона и текста.
  - Подписка на нотификатор `kAIUIBrightnessChangedNotifier` для мгновенного обновления цветов при переключении темы в Preferences.
  - Нативная отрисовка кнопок и полей ввода со скруглением, состояниями hover/pressed и акцентной подсветкой.
- **SVG-иконки для палитры**:
  - `MakeCropMarksAI_Light@2x.svg` (светлая иконка для темной темы).
  - `MakeCropMarksAI_Dark@2x.svg` (темная иконка для светлой темы).

### 2.3. Горячие клавиши и фоновый хук (Keyboard Hook & ConfigManager)
- **Thread-Level Hook**:
  - Установка хука `SetWindowsHookExW(WH_GETMESSAGE, KeyboardHookProc, NULL, GetCurrentThreadId())`.
  - **F4** (настраиваемый): открытие/скрытие панели плагина.
  - **Shift + F4** (настраиваемый): мгновенный Quick Apply по активному пресету без открытия диалога.
  - Безопасный пропуск сообщений при наборе текста в текстовых полях (`isEdit`).
- **Возможность отключения плагина**:
  - Чекбокс `Disable plugin` в настройках (`⚙`) полностью отключает обработку хоткеев.
- **Система 8 быстрых пресетов**:
  - Кнопки `[1]` .. `[8]` на панели для быстрого переключения.
  - Хранение в `%APPDATA%\MakeCropMarksAI\presets.json` и `settings.ini`.
  - Сохранение настроек в активный слот кнопкой `Save`.

## 4. История изменений (Changelog)

### v1.11 (2026-11-03)
- **Пространственная кластеризация спусков, единая группа меток и гарантия нижнего Z-Order**:
  - **Единая группа `Crop Marks` для всего выделенного блока**:
    - Устранено дробление меток на отдельные группы при `Grouping: Marks only`. Все созданные метки блока карточек теперь собираются в **одну аккуратную группу "Crop Marks"** в палитре слоев.
  - **Гарантия размещения меток строго под макетом (Send to Back)**:
    - Все элементы макета в блоке принудительно упорядочиваются поверх созданной группы меток (`sAIArt->ReorderArt(ti.art, kPlaceAbove, marksGroup)`). Метки гарантированно находятся в самом низу и никогда не перекрывают карточки или текст.
  - **Исправление улета координат на соседних артбордах**:
    - В `GetObjectBounds` добавлен предохранитель центров: если `GetArtTransformBounds` вернул локальные координаты повернутых или перенесенных на 2-й артборд объектов (смещение центра > 5 pt), движок автоматически использует мировые координаты `GetArtBounds`. Метки на 2-м артборде строятся точно по макету.
  - **Автоматическая пространственная кластеризация (`BuildClusters`)**:
    - Выделенные объекты объединяются в кластеры по расстоянию (порог 50 pt / ~18 мм).
    - Карточки на одном артборде (в сетке 2x2 встык) объединяются в единый спуск: опция `Only perimeter` отсекает внутренние стыки и строит только внешний контур.
    - Объекты на разных артбордах автоматически разделяются на независимые кластеры со своими собственными метками без межартбордных искажений.
  - **Сборка и дистрибуция**:
    - Скомпилирован `CropMarksAI.aip`, версионированный бинарник `build/x64/CropMarksAI_v1.11.aip` и упакован архив `Build_DEV/CropMarksAI_Plugin_v1.11.zip`.

### v1.10 (2026-11-03)
- **Полная изоляция объектов и исправление бага с межартбордной склейкой групп**:
  - **Устранение критической ошибки `GetFirstArtOfLayer`**:
    - Ранее вызов `sAIArt->GetFirstArtOfLayer(layer, &layerGroup)` ошибочно принимался за контейнер слоя; при наличии на слое группы (карточки) метки помещались `kPlaceInsideOnBottom` прямо внутрь этой группы, раздувая её Bounding Box на соседний артборд.
    - Все контейнеры меток `marksGroup` ("Crop Marks") теперь создаются строго относительно целевого объекта через `kPlaceBelow, targetArt` в том же z-order контексте.
  - **Автономная обработка каждого объекта в режиме `Each object in selection`**:
    - Каждый выделенный объект получает свою изолированную группу меток.
    - В режиме группировки `Marks and selection` группируется строго один конкретный объект со своими собственными метками. Объекты с разных артбордов или разные элементы макета больше никогда не объединяются в одну общую группу!
  - **Интеллектуальная фильтрация и автоочистка старых меток (`Crop Marks`)**:
    - Группы с именем `"Crop Marks"` автоматически исключаются при сборе выделения (`GetSelectedArt`), предотвращая создание меток вокруг меток.
    - Добавлен метод `RemoveExistingCropMarks`, который перед расчетом Bounding Box очищает старые вложенные или соседние группы меток, гарантируя корректные границы объекта даже при повторном запуске.
  - **Исправление фильтрации периметра (`Only perimeter`) для распределенных объектов**:
    - Логика проверки внешних сторон переведена с общего габаритного объединения всех объектов на проверку физического соприкосновения встык (`tol = 2.0 pt`).
    - Объекты на разных артбордах или с зазорами гарантированно получают полные метки со всех 4 сторон, а внутренние метки подавляются строго в плотных сетках (например, спуск визиток 3x8).
  - **Снятие выделения с созданных меток**:
    - На всех созданных линиях и группе `marksGroup` сбрасывается атрибут выделения (`kArtSelected = 0`), чтобы они не захватывались в последующие операции пользователя.
  - **Сборка и дистрибуция**:
    - Скомпилирован `CropMarksAI.aip`, версионированный бинарник `build/x64/CropMarksAI_v1.10.aip` и упакован архив `Build_DEV/CropMarksAI_Plugin_v1.10.zip`.
